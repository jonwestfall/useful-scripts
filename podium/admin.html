Storage

A consistent snapshot, taken safely while the server is running. It holds accounts, courses, connection settings, library entries and session timelines — but not the files themselves: uploads and session photos live on disk beside the database. Restoring this alone gives you every entry pointing at bytes that are not there, so a real backup is the whole data directory. See deploy/README.md.
