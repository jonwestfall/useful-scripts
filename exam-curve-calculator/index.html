Documentation

Quick start
  1. Copy a column of scores from your gradebook or spreadsheet and paste it into the Scores box.
  2. Set Points possible (default 100).
  3. Pick a curve. Results, histogram and the per-student table update immediately.
  4. When you like a curve, press Copy curved scores and paste the column back into your gradebook. The order matches what you pasted in.
Privacy

All calculations happen in your browser with JavaScript. The page does not send, save, or log scores anywhere: it has no server component, uses no cookies or local storage, loads no outside scripts, fonts, or analytics, and carries a Content-Security-Policy that tells the browser to refuse any network connection from the page (connect-src 'none'). Scores disappear when you close or reload the tab. The only way data leaves the page is if you use Copy, which places the curved scores on your device's clipboard.

The page itself is downloaded once from GitHub Pages like any web page; your scores are never part of that request.

What gets accepted as input
  • Numbers separated by new lines, commas, semicolons, tabs, or spaces. Decimals like 87.5 are fine.
  • A trailing percent sign is ignored (85% is read as 85).
  • Anything that isn't a number (names, headers, ABS, blanks) is skipped. The count of skipped items is shown under the box so you can check nothing was lost. Pasting only the score column is safest, because a student ID number would be read as a score.
  • Scores below 0 are kept for the statistics but treated as 0 by the square-root curve. Scores above the points possible (extra credit) are kept and shown; they are limited only if "Never exceed points possible" is checked.
The statistics
  • Mean: the sum of the scores divided by how many there are.
  • Median: the middle score when sorted; with an even count, the average of the two middle scores.
  • Standard deviation: how spread out the scores are. By default this is the population standard deviation (divide by n), appropriate when the pasted scores are your whole class. Tick "Use sample standard deviation" to divide by n − 1 instead, which matches Excel's STDEV.S. With one score, the sample version is undefined and shows a dash.
  • The curved column is computed from the new, rounded scores, so it matches what students would actually receive.
The curves

No curve

Leaves scores unchanged. Useful as a baseline to compare against.

Flat curve (add points)

Adds the same number of points to everyone: new = score + points. "Lift top score to max" fills in max − highest score, so the best score becomes exactly the points possible. A negative value subtracts points. Everyone moves the same amount, so the standard deviation does not change, except where the cap cuts off the top.

Square-root curve

new = max × √(score ÷ max). With max = 100 this is the familiar 10 × √score. It lifts low scores a lot and high scores a little, and 0 and the maximum stay fixed. It compresses the spread of scores, so the standard deviation shrinks.

Options

  • Never exceed points possible: limits curved scores to the maximum. On by default.
  • Round new scores to: whole number, one or two decimals, or none. Rounding is to nearest, with halves rounding up.
Histogram and letter grades
  • Bars are as wide as the bar width you choose, starting at 0 (for example 0–10, 10–20, …). A score on a boundary goes in the higher bar, except the very top boundary, which is included in the last bar so a perfect score is counted. Grey bars are the original scores and blue bars the curved ones; the number above each blue bar is its count.
  • Letter-grade cutoffs are percentages of the points possible, and a score at the cutoff earns the higher grade. Defaults are 90/80/70/60, with anything lower an F. Edit them to match your syllabus. Letters use the unrounded percentage of the displayed score.
Using it on an iPad
  • Open the GitHub Pages address in Safari. Tap Share → Add to Home Screen for an app-like icon. (Because the page keeps nothing, it needs a connection the first time it loads.)
  • To paste a column from Numbers or Excel: select the cells, tap Copy, then tap in the Scores box and choose Paste.
  • Text sizes, buttons, and fields are large for touch use; rotate to landscape for a wider chart. The page also follows the device's light or dark setting.
Hosting on GitHub Pages

This is a single self-contained file, exam-curve-calculator/index.html, in the useful-scripts repository. In the repository's Settings → Pages, publish from the branch containing it (root folder). The calculator will then be at https://<user>.github.io/useful-scripts/exam-curve-calculator/. It can also be opened directly from disk by double-clicking the file.

Limits and cautions
  • Check the curve against your syllabus and institutional policy; this tool computes numbers, it doesn't decide fairness.
  • Very large pastes (tens of thousands of scores) work but the per-student table will be long.
  • Floating-point arithmetic can cause tiny differences (for example in the 15th decimal place); with the default rounding to 0.1 you will not see them.
